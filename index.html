How the numbers are calculated

  • Total cost = litres × price per litre. The receipt total you type is only compared with it (difference above max(1, 0.5%) is flagged).
  • Distance = this odometer reading − the previous reading of the same vehicle.
  • Fuel economy (km/L) = distance ÷ litres, using the full-tank-to-full-tank method: fill the tank completely each time.
  • Cost per km = total cost ÷ distance. Only valid intervals (distance above 0) count.
  • The first record of each vehicle is a starting point. It has no previous reading, so it shows no km/L and no cost per km.
  • Alerts: km/L more than 15% below the vehicle's own average, or price per litre more than 10% above its own average.
